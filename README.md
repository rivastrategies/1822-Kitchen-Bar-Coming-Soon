# 1822 Kitchen & Bar

Pre-opening website for 1822 Kitchen & Bar in Memorial, Houston.

This design incorporates the approved hero direction recovered from the earlier production package: “Texas roots. A new table on Memorial Drive.” It deliberately avoids unconfirmed cuisine, opening-date, hours, chef, and reservation claims.
